# 本机 AI 助手

本机 AI 模式是用户主动启用的候选内容适配层。公开 GitHub Pages 和三个离线 HTML 不包含 AI 网络客户端。启动 `npm run start:ai` 后，在 `http://127.0.0.1:8001` 使用 AI 助手。

## 数据与权限

- 选择 OpenAI 或 DeepSeek，输入自己的 API Key，测试连接后选择账户可用的文本模型。这里使用 API 计费，不复用 Codex / ChatGPT 登录或订阅额度。
- 测试连接仅向所选服务商请求模型列表；用户点击发送或生成修改稿，才发送当前简历文本、JD 和当前对话。发送预览显示实际提交的文本。默认遮蔽姓名、简历名称、电话、邮箱及个人链接的已知值；这不是完整匿名化，正文、JD 或自行输入的文字仍可能包含其他个人信息。
- 图片、文件句柄、目录列表、历史快照和排版元数据不发送。AI 只返回候选文本；事实由用户核实，工具不保证模型输出真实。
- 浏览器中的 JD、对话和候选稿仅存在当前页面内存。API Key 输入后通过同源请求交给本机服务，输入框清空；服务按页面会话保存在内存，断开连接、过期或服务退出后清除。不写入 localStorage、IndexedDB、文件或日志。关闭页面不能保证立即清除服务内存；可先断开连接或退出服务。页面会话最长六小时。
- 本机服务仅监听 IPv4 回环地址，检查 Host、Origin 和页面会话令牌，不接受自定义上游地址，也不提供任意文件访问或代理。不要通过公网隧道暴露该服务。
- OpenAI 请求设置 `store: false`。服务商仍按自身政策处理请求，这不等于零保留。DeepSeek 按其服务政策处理请求。停止生成会中止本地连接，上游可能已产生费用。
- 候选稿通过现有 Schema 校验后，对比原文，再由用户确认创建未关联的新草稿。首次保存创建新文件，原来源文件不自动更新。照片和全局排版从本地快照恢复；局部格式不按位置套用，需重新检查。
- 发送后的编辑、切换简历或修改 JD 会使候选稿过期，须重新生成。导出 HTML 清除整个 AI 界面、连接令牌和客户端脚本，恢复为离线副本；PDF 打印隐藏 AI 界面。

## 发布边界

该功能是本机使用版本。公开离线产物继续执行禁止网络 API、匿名样例、敏感信息扫描和构建一致性检查。新增网络层还须通过本机来源拒绝、密钥隔离、流中断、格式校验、来源保护和导出清理测试。对外推广或部署 AI 服务前需完成独立隐私与安全审核；本机开发验收不等同于独立审核。

## 官方接口

- [OpenAI API 认证](https://developers.openai.com/api/reference/overview)
- [OpenAI Responses](https://developers.openai.com/api/docs/guides/migrate-to-responses)
- [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)
- [DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/)

两家接口由独立适配器处理；错误只显示本地固定说明，不回显上游响应、密钥或简历。模型列表成功表示认证可用，实际文本生成能力及余额以发送结果为准。
